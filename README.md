# /velvet

A single-page personal site with a sensual, softcore aesthetic: candlelit wine tones, italic serif type, and suggestive but non-explicit copy. Pure HTML and CSS, no build step, no images.

## Deploy on GitHub Pages

1. Create a repo named `<your-username>.github.io`.
2. Add `index.html`, `style.css` and this README.
3. Commit and push to `main`.
4. In the repo, go to Settings → Pages, choose "Deploy from a branch", then `main` / root.
5. Your site goes live at `https://<your-username>.github.io/`.

## Customize

- Text and links: edit `index.html`.
- Colors: change the variables at the top of `style.css` (`--wine`, `--rose`, `--gold`).
- Fonts: add a Google Fonts `<link>` for Cormorant Garamond if you want it to load on every device.

Keep any photos you add consensual, adults-only and non-explicit, and make sure you own the rights to them.
