# ncrus4su.github.io

A whimsical pastel personal site with an animated gradient sky, drifting blobs and floating sparkles.

## Deploy

1. On GitHub, create a **public** repo named exactly `ncrus4su.github.io`.
2. Upload `index.html`, `style.css`, `script.js` (and this README) to the repo root.
3. Settings → Pages → Deploy from branch → `main` / root.
4. Visit https://ncrus4su.github.io after a minute or two.

## Customize

- Replace the placeholder text, links and emoji tiles in `index.html`.
- Tweak the palette in the `:root` variables at the top of `style.css`.
- Fonts: Fredoka (headings), Quicksand (body), Caveat (handwritten accents).
- Animations respect `prefers-reduced-motion`.
